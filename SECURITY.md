# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

BTGS Core is in development; there is no mainnet release yet.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue or post in public channels.

Send the details by email to the BTGS tech lead: greenminer@bitcoingoldbtgs.com
(not for support). You will get an answer within a few days, and we will agree
with you when the issue can be made public.

Never send private keys or wallet files.
